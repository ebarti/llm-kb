## Overview

BM25 (Best Matching 25) is the most widely used ranking algorithm for keyword-based information retrieval. It estimates document relevance to a query by weighing term frequency, inverse document frequency, and document length — refining the simpler TF-IDF approach with diminishing returns for repeated terms and length normalization.

## The Formula

```
BM25(D,Q) = Σ IDF(q) × [TF(q,D) × (k₁+1)] / [TF(q,D) + k₁×(1-b+b×|D|/avgdl)]
```

Where:
- **IDF(q)**: Inverse document frequency — how rare the term is across the collection (rare terms are more informative)
- **TF(q,D)**: Term frequency — how often the term appears in the document
- **k₁**: Controls term frequency saturation (typically 1.2-2.0). Higher values give more credit for repeated terms; lower values cause saturation faster
- **b**: Document length normalization (typically 0.75). Controls how much longer documents are penalized. b=0 means no length normalization; b=1 means full normalization
- **|D|/avgdl**: Document length relative to average document length

## Key Properties

1. **Term frequency saturation**: Unlike raw TF-IDF, BM25 has diminishing returns for repeated terms — the 10th occurrence of a word adds less to the score than the 1st
2. **Length normalization**: Longer documents are penalized to prevent bias toward verbose content
3. **Determinism**: Same query + same collection = identical results every time
4. **Efficiency**: Operates on sparse inverted indexes with fast lookup

## BM25F Variant

BM25F extends BM25 to handle multiple text fields per document with different weights. For example, in [[entities/weaviate]] (v1.17+), a title match can be weighted higher than a body match. This is important for structured documents where field importance varies.

## Role in Hybrid Search

BM25 provides the keyword component of [[concepts/hybrid-search]] systems. It runs in parallel with [[concepts/vector-search]], and results are merged via Reciprocal Rank Fusion (RRF). The fusion formula H = (1-alpha)K + alphaV allows tuning the balance between keyword precision and semantic recall. See [[concepts/hybrid-search]] for details.
