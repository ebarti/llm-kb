## Overview

The Memex (from "memory" + "index") is a hypothetical device described by [[entities/vannevar-bush]] in his 1945 essay "As We May Think." Bush envisioned a desk-sized electromechanical machine using microfilm to store an individual's entire library, with the revolutionary ability to create **associative trails** — links between any two items — mirroring the way human memory works through association rather than hierarchical filing.

## Key Innovations

### Associative Indexing
Rather than organizing information in hierarchical trees (alphabetical, chronological, categorical), the Memex user could create **trails** linking any document to any other. This was a radical departure from library science's classification systems and anticipates both [[concepts/hypertext]] and the World Wide Web.

### Personal Knowledge Store
The Memex was explicitly personal — "a sort of mechanized private file and library." It stored not just documents but the user's annotations and link trails. This makes it the conceptual ancestor of [[concepts/personal-knowledge-management]] and [[concepts/second-brain]] systems.

### Knowledge Sharing
Users could share their associative trails with others — one researcher's chain of connections through a topic could be handed off as a "new form of encyclopedia."

## Influence Chain

The Memex set in motion a chain of innovations:

1. **Memex** (Bush, 1945) -> 2. **Augmenting Human Intellect** ([[entities/douglas-engelbart]], 1962) -> 3. **Hypertext** ([[entities/ted-nelson]], 1965) -> 4. **NLS / Mouse / GUI** (Engelbart, 1968) -> 5. **World Wide Web** (Berners-Lee, 1989) -> 6. **Obsidian / Roam / PKM tools** (2020s) -> 7. **LLM Knowledge Bases** (Karpathy, 2026)

## Connection to LLM Knowledge Bases

Modern [[concepts/llm-knowledge-base]] systems fulfill Bush's vision more completely than any prior technology:
- Personal knowledge store with all source documents (raw/ directory = microfilm library)
- Associative linking via wikilinks (= Bush's trails)
- LLM-maintained cross-references (= Bush's encyclopedia with mesh of trails)
- Natural language querying (= Bush's vision of intuitive access)

The key difference: Bush imagined the user creating all trails manually. In the LLM-KB model, the LLM creates and maintains the associative links automatically.
