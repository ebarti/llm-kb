## Key Points
- Founded 1960 by Ted Nelson; the first hypertext project
- Nelson coined "hypertext" in 1965 ACM paper
- Key innovations: bidirectional links, transclusion (including content from other documents), version tracking
- Autodesk funded development 1988-1992; never achieved wide release
- Wired (1995) called it "longest-running vaporware in computing history"
- Concepts anticipated features the web still lacks (bidirectional links, micropayments, content provenance)

## Detailed Summary

[[entities/ted-nelson]] conceived [[concepts/hypertext]] while a Harvard sociology student in 1960, attempting to create a system for nonsequential writing. In his 1965 ACM paper, he introduced "zippered lists" and coined the term "hypertext."

Project Xanadu's design was radically more ambitious than what the web eventually became. [[concepts/transclusion]] allowed documents to include live content from other documents — not copies, but references to the originals. Bidirectional links meant connections were visible and navigable from both endpoints, eliminating the broken links that plague the web. A built-in royalty system would enable micropayments for content access.

The 17 Original Rules specified unique identification of all entities, visible links from all endpoints, secure redundant storage, and open protocols — a vision closer to a global knowledge operating system than a document delivery mechanism.

Development was plagued by scope creep and internal conflicts. Autodesk funded the project from 1988 to 1992 before divesting. The code was released as open source (Project Udanax) in 1998. OpenXanadu appeared in 2014 as a web-based demonstration.

The relationship to the World Wide Web was contentious. Nelson and his team viewed the web as a degraded version of their vision — one-directional links, broken URLs, no content provenance. But the web shipped, and Xanadu largely didn't.
