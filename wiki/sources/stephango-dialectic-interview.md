## Key Points

- Obsidian operates with five manifesto principles: independence, user-only funding, small team (7-12), privacy, data durability
- "The company is secondary to my personal goals of using the tool I want" — builds for himself first
- "File over app" is a "civilizational stance": plain text formats maximize survival chance over a thousand years
- "The recipe for success is caring more than someone else" — design philosophy
- Plugin architecture lets millions customize without the team building everything — tools conform to users
- "Zigzagging" development approach: alternate between maximalist exploration and minimalist shipping deadlines
- Constraints enable freedom — "self-imposed constraints become your signature"
- No venture capital, no investors — funded entirely by users

## Detailed Summary

This interview provides the deepest window into [[entities/steph-ango]]'s philosophy and how it shapes [[entities/obsidian]]. The five manifesto principles explain why Obsidian has evolved differently from VC-backed competitors like [[entities/notion]]: without investor pressure for growth, the team can prioritize craftsmanship and user data durability over feature velocity and lock-in.

The "dogfooding" principle — Ango uses Obsidian as his primary tool daily — creates an unusually tight feedback loop. This is rare among CEOs of productivity tools and explains many of Obsidian's design choices: the emphasis on keyboard shortcuts, local performance, and minimal UI chrome.

The plugin architecture philosophy is architecturally significant: rather than building every feature internally (Notion's approach), Obsidian provides a robust API and lets the community build 2,700+ plugins. This is the same extensibility model that makes the LLM-KB approach possible — the vault's file-based structure means external tools (LLMs, scripts, MCP servers) can operate on it without Obsidian's explicit support.

The "zigzagging" development method (alternate between adding and removing features) explains Obsidian's relatively slow but high-quality release cadence. The Bases feature (November 2025) spent years in exploration before shipping.
