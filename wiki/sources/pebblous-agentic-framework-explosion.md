## Key Points

- Three stages: single-shot inference (2022-23) → tool-calling agents (2023-24) → autonomous operating agents (2025+)
- agent-lightning (Microsoft): reinforcement learning approach for training agents
- hermes-agent (NousResearch): self-improvement via skill generation and user modeling
- superpowers (obra): TDD methodology for trustworthy autonomous code, 129K GitHub stars
- Unifying insight: data quality is the ceiling for all autonomous agent approaches

## Detailed Summary

Pebblous traces the evolution of autonomous AI through three stages and analyzes three major 2025 open-source frameworks. Each addresses a different operational challenge: agent-lightning optimizes training via RL, hermes-agent enables self-improvement through accumulated skills and user modeling, and superpowers applies TDD to ensure code trustworthiness.

The article's strongest contribution is the unifying thesis that [[concepts/data-quality-bottleneck]] applies universally: RL agents need accurate reward signals, self-improving agents need validated skills, and autonomous coders need comprehensive test coverage. "The more autonomous the agent, the less human oversight there is — and the more the quality of the underlying data sets the ceiling on results."
