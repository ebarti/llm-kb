- Five evaluation criteria: token efficiency, productivity impact, code quality, repo understanding, privacy/security
- Top tier: Cursor (flow/shipping), Claude Code (reasoning/debugging), Codex (agent-native), Copilot (frictionless), Cline (flexibility)
- Cursor: $2B annualized revenue by March 2026, $29.3B valuation

- Runner-ups include RooCode, Windsurf, Aider, Augment, JetBrains Junie, Gemini CLI

## Detailed Summary

This Faros AI review provides the most comprehensive competitive analysis of the AI coding agent landscape. The key insight is that tool selection depends on what dimension you optimize for: speed and polish (Cursor), reasoning depth (Claude Code), cost control (Cline), or reliability (RooCode).

The market has matured beyond simple autocomplete into distinct categories: IDE-native agents ([[entities/cursor]], Windsurf), CLI agents ([[entities/claude-code]], [[entities/aider]]), autonomous agents ([[entities/devin]], Codex), and VS Code extension agents (Cline, RooCode). Each category serves different workflow preferences and use cases.

Enterprise guidance emphasizes A/B testing tools rather than picking a single winner, and measuring downstream effects on PR cycle time, code quality, and rework rates rather than simple adoption metrics.
