## Key Points

- Released May 22, 2025 with Opus 4 and Sonnet 4
- Opus 4: 72.5% SWE-bench Verified, 43.2% Terminal-bench -- "world's best coding model"
- Sonnet 4: 72.7% SWE-bench Verified, balances performance and efficiency
- Extended thinking with tool use (beta): models alternate between reasoning and tools
- Parallel tool execution: multiple tools simultaneously
- 65% fewer shortcut behaviors compared to Sonnet 3.7 on agentic tasks
- Claude Code GA: VS Code, JetBrains IDE integrations, GitHub Actions, extensible SDK
- Pricing unchanged from Claude 3: Opus $15/$75, Sonnet $3/$15

## Detailed Summary

Claude 4 represented Anthropic's push into agentic AI leadership. The key innovation was extended thinking with tool use -- allowing models to interleave reasoning and tool calls within a single turn. Opus 4 was positioned as "the world's best coding model" with the highest SWE-bench Verified score at launch. The 65% reduction in shortcut behaviors addressed a persistent challenge in agentic systems where models take expedient but incorrect paths. Claude Code's general availability with IDE integrations and an extensible SDK marked the commercialization of agentic coding.
