## Key Points

- "File over app is a philosophy: if you want to create digital artifacts that last, they must be files you can control, in formats that are easy to retrieve and read."
- Apps are ephemeral; files can persist for centuries — like Egyptian hieroglyphs outlasting their chisels
- "If you want your writing readable on computers from the 2060s or 2160s, it's important that your notes can be read on computers from the 1960s"
- An "appeal to tool makers to accept that all software is ephemeral"
- Obsidian embodies this by storing everything as plain markdown files on the user's device

## Detailed Summary

Steph Ango, CEO of [[entities/obsidian]], articulates a philosophy that frames the relationship between software and data. The core insight is that throughout history, human ideas survived through durable mediums — clay tablets, manuscripts, paintings, tapestries — that required minimal technology to access. Today's cloud-dependent, proprietary-format files break this pattern.

The philosophy serves as both a user guide (choose tools that produce portable files) and a challenge to developers (build tools that prioritize user data ownership over lock-in). Obsidian itself is the embodiment: plain markdown files, stored locally, readable by any text editor.

The argument has become influential in the software community, with "file over app" becoming a shorthand for data portability and longevity as first-class design priorities.

## Notable Quotes
