## Key Points

- RLVR (Reinforcement Learning from Verifiable Rewards) replaces SFT+RLHF as dominant training formula
- LLMs are "ghosts" with "jagged intelligence" — genius in some domains, grade-school in others
- Cursor demonstrates the emerging LLM middleware/app layer (context engineering, autonomy sliders)
- Claude Code represents localhost-first agent paradigm (private data, low-latency local interaction)
- Vibe coding democratizes software creation via natural language
- "General apathy and loss of trust in benchmarks" — RLVR makes verifiable benchmarks gameable
- Industry has realized "nowhere near 10% of their potential even at present capability"

## Detailed Summary

Karpathy's retrospective on 2025 offers a characteristically clear-eyed assessment of where LLMs stand. The most consequential insight is that RLVR has displaced RLHF as the primary alignment and capability-building mechanism. Where RLHF relies on human preference labels, RLVR optimizes against objectively verifiable rewards (math proofs, code that compiles and passes tests), enabling emergent reasoning strategies and test-time compute scaling.

His framing of LLMs as "ghosts" rather than "animals" is a deliberate challenge to anthropomorphizing AI. Where animals have coherent intelligence shaped by evolutionary pressures, LLM capabilities are jagged — shaped by the idiosyncratic mixture of text imitation rewards, puzzle-solving rewards, and arena upvotes. This framing matters for setting realistic expectations.

The analysis of Cursor and Claude Code as representing an emerging app layer is significant for this knowledge base. Cursor bundles LLM orchestration with [[concepts/context-engineering]], domain UIs, and autonomy control. Claude Code takes a localhost-first approach — agents with direct access to the user's environment. These are precisely the kinds of tools that power the [[concepts/llm-knowledge-base]] workflow.
