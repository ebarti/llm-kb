## Key Points

- Adoption growth: 29% (2022) → 70% (2023) → 76% (2024) → 84% (2025)
- 41% of all code is now AI-generated; 51% of developers use AI daily
- ChatGPT (49% regular) leads over Copilot (26% regular) and Gemini (47%)
- 55% faster task completion but 66% spend extra time fixing AI-generated code
- 90% of Fortune 100 use GitHub Copilot; 3-6 month typical enterprise rollout
- Developer sentiment declining: 60% positive (down from 70% in 2024)

## Detailed Summary

This statistics compendium from Index.dev aggregates data across Stack Overflow, GitHub, JetBrains, and industry surveys to provide the most complete quantitative picture of AI pair programming adoption and impact.

The usage pattern data is particularly revealing: 82% use AI for code writing, but only 27% for testing and 13% for code review. This confirms the [[concepts/ai-productivity-paradox]] finding that most developers use AI for the easiest, most automatable tasks rather than the bottleneck tasks (review, testing) where organizational impact would be greatest.

The declining sentiment trend (70% positive in 2024, 60% in 2025) suggests the honeymoon period is ending. The 46% who don't fully trust AI output and 45% frustrated with "almost right" suggestions indicate maturation of developer expectations.

The security statistics are alarming: 57% of AI-generated APIs left publicly accessible, 89% rely on weak authentication — suggesting AI tools reproduce insecure patterns at scale.
