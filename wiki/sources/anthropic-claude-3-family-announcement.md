## Key Points

- Released March 4, 2024 with three tiers: Haiku, Sonnet, Opus
- Opus was first model to surpass GPT-4 on several benchmarks (MMLU, GPQA, GSM8K)
- All three models have sophisticated vision capabilities (photos, charts, graphs, technical diagrams)
- 200K token context windows; select use cases support >1M tokens
- Opus achieved >99% accuracy on Needle In A Haystack evaluation
- Sonnet 2x faster than Claude 2/2.1; Haiku processes 10K-token papers in <3 seconds
- Pricing: Opus $15/$75, Sonnet $3/$15, Haiku $0.25/$1.25 per million tokens

## Detailed Summary

The Claude 3 family announcement marked Anthropic's breakthrough into competitive parity with and then leadership over GPT-4. The three-tier system (Haiku/Sonnet/Opus) became the standard for all subsequent Claude releases. Vision capabilities were a first for Claude, enabling processing of enterprise knowledge bases encoded in PDFs, flowcharts, and slides. The near-perfect Needle-in-Haystack recall demonstrated that Claude 3 could effectively use its full 200K context window, addressing the [[concepts/lost-in-the-middle]] problem that plagued earlier models.
