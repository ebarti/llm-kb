## Key Points

- PR size increased 93% year-over-year (57 to 110 lines changed)
- Individual developer output nearly tripled: 4,450 to 14,148 lines of code annually
- Medium-sized teams saw gains from 7,005 to 19,715 lines per developer
- CLAUDE.md configuration files appear in 75% of organizations
- AGENTS.md surpassed Cursor Rules as the leading agent configuration format
- Anthropic SDK reached 124 million monthly downloads by March 2026
- OpenAI Agents grew 5x during Q1 2026 to 21 million downloads
- OpenAI's PyPI lead over Anthropic compressed from 3.7:1 to 2.8:1

## Detailed Summary

Greptile's report provides hard telemetry data on how AI coding tools have transformed software engineering velocity. The tripling of individual developer output and near-doubling of PR sizes represent the most concrete evidence of [[concepts/ai-code-generation]]'s impact on raw productivity metrics. However, these output-focused metrics must be read alongside [[concepts/ai-productivity-paradox]] research showing that more code does not necessarily mean better organizational outcomes.

The standardization data is particularly revealing: CLAUDE.md appearing in 75% of organizations suggests that configuration-based AI coding workflows have become the norm, not the exception. The shift from Cursor Rules to AGENTS.md signals the industry's move from autocomplete-oriented tools to [[concepts/agentic-coding]] workflows.
