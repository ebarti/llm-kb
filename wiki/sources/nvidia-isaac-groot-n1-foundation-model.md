## Key Points

- World's first open, fully customizable foundation model for humanoid robots (March 2025)
- Dual-system architecture inspired by Kahneman: System 1 (fast reflexive action) + System 2 (slow deliberate VLM reasoning)
- Generated 780,000 synthetic trajectories in 11 hours = 9 months of continuous human demonstrations; 40% performance improvement with synthetic + real data
- N1.6 (Sep 2025) integrates Cosmos Reason VLM, enables simultaneous movement + object handling
- Newton physics engine co-developed with [[entities/google-deepmind]] and Disney Research
- Adopted by [[entities/boston-dynamics]], 1X Technologies, Agility Robotics, NEURA, Franka, LG, and others

## Detailed Summary

[[entities/nvidia-groot]] N1 represents NVIDIA's entry into [[concepts/foundation-models-for-robotics]] for humanoid systems. Released in March 2025 as open and fully customizable, it uses a dual-system architecture inspired by Daniel Kahneman's System 1/System 2 cognitive framework.

**System 1 (Fast Thinking)** is an action model that mirrors human reflexes, translating high-level plans into precise continuous robot movements. It is trained on human demonstration data and massive synthetic data generated by the NVIDIA Omniverse platform.

**System 2 (Slow Thinking)** is a vision language model that deliberately reasons about environmental context and instructions to plan actions. Together, these enable robots to handle both reactive motor control and deliberate task planning.

The synthetic data pipeline is remarkable: NVIDIA generated 780,000 trajectories (equivalent to 9 months of nonstop human demonstration) in just 11 hours using Omniverse simulation. Combining this synthetic data with real demonstrations yielded a 40% performance improvement.

The September 2025 update (N1.6) integrated NVIDIA Cosmos Reason, a reasoning VLM that acts as the robot's "deep-thinking brain," turning vague instructions into step-by-step plans. N1.6 also enabled simultaneous locomotion and manipulation -- a key capability gap in earlier versions.

Supporting infrastructure includes the Newton physics engine (co-developed with [[entities/google-deepmind]] and Disney Research, compatible with MuJoCo), Isaac GR00T Blueprint for synthetic data generation, and open-source datasets on Hugging Face.
