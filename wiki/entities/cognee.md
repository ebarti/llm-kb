## Overview

Cognee is a cognitive memory layer designed for agentic AI systems. It provides hybrid graph + vector memory with modular extraction and enrichment pipelines, enabling persistent cross-session memory for AI agents.

## Key Features

- **Hybrid memory**: Graph + vector embeddings in unified storage
- **Modular pipelines**: Customizable extraction and enrichment
- **Graph backends**: NetworkX, [[entities/falkordb]], [[entities/neo4j]]
- **Data connectors**: 30+ sources (documents, images, audio)
- **Incremental learning**: Updates without full reprocessing

## Best For

Agentic AI systems requiring persistent, cross-session memory with modular architectures. Ideal for evolving knowledge bases where incremental updates are critical.
