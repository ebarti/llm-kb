## Overview

OWASP (Open Worldwide Application Security Project) is a nonprofit foundation focused on improving software security. Known for its influential "Top 10" vulnerability lists, OWASP expanded into AI/ML security with its GenAI Security Project.

## Key Contribution

In 2025, OWASP published its Top 10 for LLMs, ranking [[concepts/prompt-injection]] as the #1 AI security risk (LLM01:2025). This classification elevated prompt injection from a niche concern to a mainstream security priority.
