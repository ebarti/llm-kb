## Overview

Devin is the first system marketed as a fully autonomous AI software engineer. Created by Cognition Labs (CEO Scott Wu, CTO Steven Hao, 10-person team funded by Peter Thiel's Founders Fund), Devin demonstrated that AI agents could go beyond code completion to handle entire software engineering workflows: planning, coding, debugging, and testing.

## Key Features

- Autonomous code writing, running, and testing
- Sandboxed compute environment with shell, code editor, and browser
- Long-term reasoning and planning across thousands of decisions
- Context recall at every step
- Learning over time and self-correction
- **Devin Wiki** (2025): Machine-generated software documentation
- **Devin Search** (2025): Interactive code Q&A engine

## Significance

Devin's March 2024 announcement catalyzed the [[concepts/agentic-coding]] field. The 7x improvement on [[concepts/swe-bench]] (from 1.96% to 13.86%) proved that autonomous software engineering was viable, triggering a wave of investment and competition from Anthropic ([[entities/claude-code]]), OpenAI, Google, and others.

By 2026, leading agents score 80%+ on SWE-bench Verified, making Devin's initial score seem modest — but it was the proof point that launched the field.
