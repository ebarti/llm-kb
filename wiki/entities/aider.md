## Overview

Aider is an open-source, CLI-based AI coding agent that integrates directly with Git workflows. It provides transparent diffs, supports multiple LLM providers, and allows self-hosted deployment. It is the leading open-source alternative in the [[concepts/agentic-coding]] space.

## Key Facts

- **Type:** Open-source CLI agent
- **Pricing:** Free (open source) + LLM provider costs
- **License:** Open source
- **Interface:** Terminal/CLI
- **Key Feature:** Git-native workflow with transparent change review

## Strengths

- Full transparency — all changes visible as standard Git diffs
- Model flexibility — works with any LLM provider
- Self-hosted compatible — no data leaves your infrastructure
- Structured CLI-native refactors
- Active open-source community

## Weaknesses

- Requires terminal comfort
- No GUI or IDE integration
- Token management is the user's responsibility
- Less polished UX than commercial alternatives

## Benchmark Performance

GPT-5 via Aider achieved 88% on SWE-bench (February 2026) — the highest recorded benchmark score, demonstrating that the tool's architecture effectively leverages model improvements.
