## Overview

Physical Intelligence (π) is a San Francisco-based AI robotics company building general-purpose robot foundation models. The company aims to provide for physical intelligence what LLMs provide for language: a single model that can control diverse robots across diverse tasks.

## Key Facts

- **Type**: organization (startup)
- **Founded**: 2023
- **HQ**: San Francisco, CA
- **Funding**: $400M+
- **Key Product**: [[entities/pi0]] (3B-parameter VLA model)
- **Notable for**: First system to fold laundry and assemble boxes; open-source release

## Key Contributions

1. **[[entities/pi0]]**: 3B-parameter [[concepts/vision-language-action-models]] using [[concepts/flow-matching]] for 50Hz continuous control. Trained on 7-8 robot types across 68 tasks.
2. **π0-FAST**: Autoregressive variant with DCT-based FAST tokenization, 5x faster training.
3. **Open-source release**: Models and code available via Hugging Face LeRobot and openpi GitHub repository.
