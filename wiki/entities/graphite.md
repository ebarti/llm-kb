## Overview

Graphite is a developer workflow platform that added AI-powered code review (Graphite Agent) in October 2025. The tool provides real-time PR feedback, customizable prompts, and a conversational AI interface ("Graphite Chat") within the PR view.

## Key Facts

- **Type:** Developer workflow platform with AI code review
- **Launched:** October 2025 (Agent feature)
- **Feedback Rate:** 96% positive
- **Action Rate:** 55% of flagged issues result in code changes (vs. 49% for human reviewers)
- **Unhelpful Comment Rate:** Under 3%
- **Integration:** GitHub and VS Code
- **Special Feature:** Stacked pull requests support

## Significance

Graphite Agent's 55% developer action rate exceeding human reviewers' 49% is a milestone — it suggests AI code review has crossed the threshold from "supplementary noise" to "actionable feedback that developers trust more than peers for routine issues."
