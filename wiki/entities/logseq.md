## Overview

Logseq is an open-source, local-first knowledge management tool that combines outliner-style editing with bidirectional linking and graph visualization. It emerged as a free, privacy-respecting alternative to [[entities/roam-research]], offering similar block-based architecture with the local-first philosophy of [[entities/obsidian]].

## Key Features

- **Block-based architecture**: Every bullet point is an individual, referenceable block
- **Open-source**: Fully transparent codebase, community-driven development
- **Local-first**: Data stored on user's device (Markdown or EDN format)
- **Advanced querying**: Filter and search information based on metadata, tags, and content
- **Graph visualization**: Visual representation of note connections
- **Git-friendly**: Version control integration via file-based storage

## 2026 Performance

Version 0.12.6 benchmarks: 90% responsiveness rate, 250ms latency — slightly behind Obsidian's 95%/<200ms but with the advantage of full open-source flexibility.

## Positioning

Logseq occupies a distinctive niche: it combines Roam's block-level referencing with Obsidian's local-first storage. Its outliner interface is optimized for hierarchical structuring and daily journaling, making it particularly suited for structured knowledge organization and developers who value open-source transparency.

## 2026 Developments

- v1.5.0 improved query systems and refined knowledge graph visualization
- AGPL licensing ensures community forks can sustain the ecosystem if the company folds
- Pricing: Free and open-source, no paid features required
