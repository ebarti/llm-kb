## Overview

Anki is an open-source spaced repetition software (SRS) platform widely considered "the most sophisticated spaced repetition platform available." It uses scientifically grounded algorithms to schedule flashcard reviews at optimal intervals, moving information from short-term to long-term memory with maximum efficiency.

## Key Features

- **FSRS Algorithm**: The Free Spaced Repetition Scheduler uses machine learning to optimize review intervals based on individual performance patterns, replacing the older SM-2 algorithm
- **Multimedia Support**: Cards can include images, audio, formatted text, and LaTeX
- **Cross-platform**: Desktop (Windows, Mac, Linux), mobile (iOS, Android), and web
- **Open-source**: Free on most platforms, with extensive community add-ons
- **Customizable**: Deck structures, card templates, and scheduling parameters are all configurable

## Role in PKM

Anki bridges the gap between understanding and retention in personal knowledge management. While PKM systems like [[concepts/zettelkasten]] and [[concepts/evergreen-notes]] excel at building connections and generating insights, they don't ensure knowledge is recallable when needed. Anki fills this gap.

Integration pathways include:
- **Obsidian plugins**: Create flashcards directly from Obsidian notes
- **RemNote**: Combined note-taking and spaced repetition in one tool
- **Manual export**: Create cards from key concepts discovered during note-taking
