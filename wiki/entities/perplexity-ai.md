## Overview

Perplexity AI is an AI-powered research and search tool that provides citation-backed answers drawn from real-time web search. It has emerged as the leading tool for the discovery phase of research workflows, offering traceable sources and minimal distraction.

## Key Facts

- **Type**: AI research tool / search engine
- **URL**: https://perplexity.ai
- **Pricing**: Free / Pro $20/month
- **Notable for**: Citation-backed real-time search, Deep Research mode for autonomous multi-source synthesis

## Key Features

- Source links for every claim
- Focus Mode for specialized search contexts
- Deep Research mode: autonomously plans research strategy, searches/reads dozens of sources, produces structured synthesis
- No login required for basic use
- Clean UI optimized for research workflows
