## Overview

LM Studio is a desktop application that provides a graphical interface for downloading, configuring, and running LLMs locally. It is the most accessible [[concepts/local-llm-inference]] tool for non-technical users, with a visual model browser, drag-and-drop simplicity, and automatic hardware detection.

## Key Features

- Polished GUI with intuitive interface
- Model browser for easy discovery and download
- Vulkan offloading for integrated Intel/AMD GPUs
- Excellent Apple Silicon optimization
- OpenAI-compatible API server (experimental function calling)
- No command-line required

## Best For

- Beginners exploring local LLMs for the first time
- Users who prefer graphical interfaces
- Systems with integrated GPUs (Vulkan offloading advantage)
- Quick model comparison and experimentation
