## Overview

Devin, developed by Cognition Labs, was the first system marketed as a fully autonomous AI software engineer when it launched in March 2024. It operates in a sandboxed environment with its own shell, browser, and editor — the same tools human developers use — enabling end-to-end task execution from planning to deployment.

## Key Facts

- **Type:** Autonomous task agent
- **Developer:** Cognition Labs
- **Launch:** March 2024 (first autonomous AI software engineer)
- **Pricing:** Core $20/mo (Devin 2.0, April 2025), Team ~$500/mo, Enterprise custom
- **Original Price:** $500/mo (dramatically reduced with 2.0)
- **SWE-bench (launch):** 13.86% (7x previous SOTA of 1.96%)

## Key Features

- Full sandboxed environment (shell, browser, editor)
- End-to-end task execution with planning
- Test iteration and failure recovery
- Autonomous problem-solving without human intervention

## Significance

Devin's March 2024 launch was a watershed moment for [[concepts/agentic-coding]], demonstrating that AI could perform complete software engineering tasks autonomously. The dramatic price reduction from $500/mo to $20/mo with Devin 2.0 signaled rapid commoditization of autonomous coding capabilities.

## Weaknesses

- Less mindshare than Cursor/Claude Code/Copilot in 2026
- Well-defined engineering tasks only — struggles with ambiguous requirements
- Opaque pricing on long-running operations
