## Overview

Glean is an AI-powered enterprise search platform that uses an Enterprise Graph architecture to link people, data, and processes across an organization. The platform integrates with 100+ SaaS applications and provides semantic search, conversational AI, and agentic workflow capabilities.

## Key Features

- **Enterprise Graph**: Dynamic knowledge model continuously learning from user interactions and organizational changes
- **100+ integrations**: Slack, Teams, Google Workspace, Microsoft 365, GitHub, Jira, Salesforce, and more
- **Permission-aware search**: Real-time permission checks respecting source system access boundaries
- **Code intelligence**: Cross-references code with documentation and organizational knowledge
- **Agentic workflows**: AI agents that execute multi-step tasks beyond simple search
- **RAG-powered answers**: Citation-backed responses synthesized from internal sources

## Funding and Market Position

Raised $150 million in Series F funding. Positioned as the market leader in AI enterprise search per [[sources/glean-enterprise-search-guide]], differentiated by the depth of its Enterprise Graph technology and breadth of integrations.
