## Overview

ComfyUI is an open-source, node-based visual workflow builder for AI image generation. It provides a drag-and-drop interface where users connect processing nodes (model loading, sampling, conditioning, VAE encoding/decoding) to build complex generation pipelines without code.

## Key Facts

- **Type**: tool
- **Notable for**: Most powerful workflow customization for image generation
- **Supports**: [[entities/flux]], [[entities/stable-diffusion]], and other diffusion models
- **Deployment**: comfy-pack packages workflows for API deployment
- **Alternative**: Automatic1111 (A1111) provides simpler Gradio-based UI
