# The Reality of AI-Assisted Software Engineering Productivity

## Adoption vs. Trust Paradox

84% of developers now use or plan to use AI coding tools. However, favorable views dropped from over 70% in 2023 to approximately 60% in 2025. 46% of developers distrust AI output accuracy (up from 31%). 66% cite "almost right, but not quite" code as their biggest time sink. 45% report that debugging AI-generated code consumes more effort than it justifies.

## Realistic Productivity Gains: 20-30%, Not 10x

### Google's Internal Trial (2024)
~100 engineers on enterprise-grade coding tasks. Developers using AI completed assignments approximately 21% faster (96 min vs 114 min). Senior engineers saw larger gains than junior developers.

### Multi-Company Industry Study (2024)
Microsoft, Accenture, and Fortune 100 company, ~5,000 developers. Average 26% productivity increase with Copilot. Newer developers: 35-39% speed improvement. Seasoned engineers: 8-16% gains only.

### METR Study (July 2025)
16 experienced open-source developers, large projects (>1M lines). Developers using AI took 19% longer. Developers believed they worked faster by ~20% despite being slower.

## DORA/Faros AI Productivity Paradox (2025)

10,000+ developers across 1,255 teams:
- High-AI teams completed 21% more tasks, merged 98% more PRs
- PR review times ballooned by 91%
- Bug rates increased by 9% per developer
- Average PR size jumped 154%
- No significant correlation between AI adoption and better organization-level DORA metrics

## Where AI Helps Most

- Greenfield projects and prototyping
- Boilerplate and repetitive code (unit tests, CRUD, serialization)
- Documentation and learning (44% of developers learning new tech leveraged AI)
- Codebase onboarding
- Debugging assistance (stack traces, error logs)

## Where AI Struggles

- Large legacy codebases (gains drop to 10-30%, sometimes reverse)
- Autonomous coding agents (David Cramer at Sentry: "you cannot use these agents to build software today")
- Nearly-correct code introducing subtle bugs
- Novel problem-solving beyond pattern matching

## Critical Conclusions

AI coding assistance is a "situational force multiplier" providing modest, uneven productivity boosts. Expect 20-30% productivity gains on coding mechanics for those who use tools wisely. Core software engineering skills -- system design, debugging, testing, maintenance -- remain paramount.
