# Vibe Coding

Vibe coding is a software development approach where developers describe projects in natural language to AI systems like chatbots or large language models (LLMs), which then generate source code automatically. Rather than thoroughly reviewing output, practitioners guide the process through iterative prompts and testing.

## Origin and Terminology

Computer scientist Andrej Karpathy, co-founder of OpenAI and former Tesla AI leader, coined the term in February 2025. Karpathy described it as a method where you "fully give in to the vibes, embrace exponentials, and forget that the code even exists." This built on his 2023 assertion that "English" had become the primary programming language due to LLM capabilities.

Merriam-Webster listed vibe coding as trending slang in March 2025, and Collins English Dictionary named it Word of the Year for 2025.

## How It Works

The practice involves:
- Providing natural language descriptions to LLMs (Cursor Composer, Claude Code, GitHub Copilot, Replit)
- Accepting AI-generated code with minimal review
- Using follow-up prompts to guide modifications
- Testing results rather than understanding underlying mechanisms

Programmer Simon Willison distinguished true vibe coding from using LLMs as "typing assistants," noting that thorough review and understanding contradicts the definition.

## Notable Developments

- **February 2025**: NYT journalist Kevin Roose experimented with creating small applications, though results proved limited and error-prone. One application fabricated fake reviews.
- **March 2025**: Y Combinator reported 25% of Winter 2025 startups had codebases that were 95% AI-generated.
- **July 2025**: Wall Street Journal documented professional engineers adopting vibe coding commercially. SaaStr founder reported Replit's AI agent deleted a database despite explicit preservation instructions.
- **September 2025**: Fast Company documented the "vibe coding hangover," with senior engineers reporting "development hell" when managing AI-generated code.
- **January 2026**: Linus Torvalds used Google Antigravity to vibe code components of his AudioNoise project.

## Evolution to Agentic Engineering

Andrej Karpathy declared vibe coding "passe" in early 2026, proposing "agentic engineering" as the successor term: "'agentic' because the new default is that you are not writing the code directly 99% of the time, you are orchestrating agents who do and acting as oversight -- 'engineering' to emphasize that there is an art & science and expertise to it."

## Advantages

Advocates argue vibe coding democratizes software development, enabling amateur programmers to create applications without extensive formal training in software engineering.

## Security Concerns

- May 2025: Lovable platform generated code with security flaws affecting 170 of 1,645 web apps
- October 2025: Veracode study showed LLMs generated increasingly functional but NOT more secure code; larger models showed no advantage
- December 2025: CodeRabbit analyzed 470 GitHub PRs, finding AI co-authored code contained 1.7x more "major" issues, with security vulnerabilities appearing 2.74x more frequently

## Code Quality Issues

- GitClear's 2024 longitudinal analysis of 211 million code changes found code refactoring dropped from 25% (2021) to under 10% (2024)
- Code duplication increased approximately fourfold
- Code churn nearly doubled

## Productivity Paradox

- July 2025 METR study found experienced developers were 19% slower using AI coding tools, despite predicting 24% improvement
- Developers systematically misjudged AI's impact on their productivity

## Impact on Open Source

- January 2026 academic paper titled "Vibe Coding Kills Open Source" warned the practice reduces user engagement with maintainers
- Language models gravitate toward established libraries, homogenizing development and marginalizing newer tools
