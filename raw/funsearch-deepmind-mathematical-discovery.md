# FunSearch: AI-Driven Mathematical Discovery

## Core Mechanism

FunSearch pairs a large language model (Google's PaLM 2) with an automated evaluator in an evolutionary loop. The LLM generates creative solutions as computer code, while the evaluator filters out hallucinations and incorrect outputs. High-scoring programs are returned to the pool, enabling iterative improvement. The system favors concise and human-interpretable programs.

## The Cap Set Problem

FunSearch tackled the cap set problem — finding the largest set of points in high-dimensional grids where no three points align. Mathematicians including Terence Tao have studied this for decades. The discovery represents the largest increase in the size of cap sets in the past 20 years, outperforming existing computational solvers.

Professor Jordan Ellenberg stated: "The solutions generated by FunSearch are far conceptually richer than a mere list of numbers."

## Key Innovation: Interpretability

Unlike black-box approaches, FunSearch outputs readable code explaining how solutions work. Researchers noticed symmetries in high-scoring outputs, generating new insights that refined the problem for even better solutions.

## Practical Application: Bin Packing

FunSearch discovered algorithms that pack items more efficiently than established human-designed heuristics, with potential applications in data center efficiency.

## Broader Implications

The work demonstrates LLMs can produce verifiable scientific discoveries when properly constrained, potentially becoming standard practice across mathematics and engineering challenges.
