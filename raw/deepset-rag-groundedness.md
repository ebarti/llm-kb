# Measuring LLM Groundedness in RAG Systems

## What is Groundedness?

Groundedness measures "the degree to which an answer generated by a RAG pipeline is supported by the retrieved documents." Also called faithfulness, it represents the opposite of hallucination.

## The Groundedness Score

- Ranges across a performance spectrum from poor to excellent
- Tracks changes over time through an observability dashboard
- Aggregated from actual query volumes

## Document Reference Analysis

Tracks which document positions are most frequently used to support answers:
- Ideal: Top-ranked documents used most, with usage declining by position
- Anomalies indicate retrieval quality issues

## Practical Benefits

### Cost Optimization
Limiting retrieved documents from 10 to 6 eliminated 40% of LLM processing costs while maintaining quality.

### Retrieval Improvement
- Add reranking components
- Combine multiple retrieval methods
- Fine-tune retrievers using small models

## Reference Predictor

Statement-level analysis:
- Breaks responses into individual claims
- Annotates each with source citations
- Works reliably across all LLM types
- Enables user-level verification

## Production Monitoring

Groundedness Observability Dashboard:
- Monitor across 1-60 day timeframes
- Establish quality baselines
- Identify degradation patterns
- Data-driven infrastructure decisions

## Risk Mitigation

For sensitive applications (aircraft docs, financial, legal), groundedness metrics reduce hallucination risks by providing quantifiable evidence that outputs remain anchored to source material.
