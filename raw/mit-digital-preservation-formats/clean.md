# File Formats for Long-Term Access — MIT Libraries

## Selection Criteria

When choosing formats for archival storage, prioritize:

1. **Open Standards**: Non-proprietary formats usable across multiple software tools ensure longevity beyond any single vendor's lifespan.
2. **Community Adoption**: "A file format which is relied upon by a large user group creates many more options for its users," supporting wider preservation strategies.
3. **Published Documentation**: Formats with public standards (ideally registered in the PRONOM file format registry) facilitate future accessibility.
4. **Lossless Compression**: Data should be fully preserved without quality degradation.
5. **Unencrypted Storage**: Lost passwords or keys render encrypted files permanently inaccessible.

## Recommended Formats by Content Type

| Content Type | Preferred Formats |
|---|---|
| **Text** | Plain text (US-ASCII, UTF-8, UTF-16) |
| **Tabular Data** | CSV, TSV, delimited text |
| **Statistical Data** | CSV, delimited text, HDF5 |
| **Geospatial** | GML, GeoTIFF, GeoPackage |
| **Images** | TIFF, PNG, SVG |
| **Audio** | WAVE, Broadcast WAVE, AIFF |
| **Video** | FFV1, Matroska, AVI, DPX |

## Key Insight

For text content, the MIT Libraries recommend **plain text** (US-ASCII, UTF-8, UTF-16) as the preferred preservation format. This aligns directly with the markdown-as-knowledge-substrate argument: markdown IS plain text with lightweight formatting conventions.
