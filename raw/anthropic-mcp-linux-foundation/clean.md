# MCP Donation to Linux Foundation

## The Announcement
Anthropic is donating the Model Context Protocol (MCP) to the Linux Foundation's newly established Agentic AI Foundation (AAIF). This move underscores the commitment to maintaining MCP as "an open, vendor-neutral standard."

## Agentic AI Foundation Structure
The AAIF operates as a directed fund under the Linux Foundation, co-founded by Anthropic, Block, and OpenAI. Supporting organizations include Google, Microsoft, AWS, Cloudflare, and Bloomberg. Its mission centers on ensuring agentic AI "evolves transparently, collaboratively, and in the public interest."

## MCP's Track Record
Since its introduction one year ago, MCP has achieved substantial adoption:
- Over 10,000 active public MCP servers across ecosystems
- Integration with ChatGPT, Cursor, Gemini, Microsoft Copilot, and Visual Studio Code
- Enterprise deployment support from AWS, Cloudflare, Google Cloud, and Microsoft Azure
- Claude now offers over 75 connectors powered by MCP
- November 2025 specification release introduced asynchronous operations, statelessness, and official extensions
- SDK downloads exceed 97 million monthly across Python and TypeScript

## Governance Continuity
MCP's governance structure remains unchanged. The project's maintainers will continue prioritizing "community input and transparent decision-making."

## Founding Projects
MCP joins two inaugural projects under the AAIF: goose (by Block) and AGENTS.md (by OpenAI), fostering broader ecosystem innovation.
