# Current and Future Use of LLMs for Knowledge Work

## Adoption Rates

Summer 2023: ~24.5% of knowledge workers used LLMs for work tasks, 27.8% for personal tasks, 26.9% experimented. By Fall 2024: work adoption increased to 34.6%, indicating significant growth in workplace integration.

## Four Primary Use Categories

### 1. Creation
Workers generate new artifacts and ideas. Technical workers request code snippets, viewing outputs as "starting points" requiring modification. Non-technical workers draft emails, job postings, marketing content. Personal users seek creative generations.

### 2. Information Tasks (Most Common in 2024)
- **Search**: Finding specific facts; sometimes replacing traditional search engines
- **Learning**: Gaining understanding at appropriate complexity levels. One participant noted an LLM explained Kubernetes "at the right level," matching their expertise
- **Summarization**: Condensing lengthy content; increased significantly as context windows expanded
- **Analysis**: Extracting insights from datasets (less common currently)

### 3. Advice
- **Improve**: Enhancing existing work (grammar, code refinement)
- **Guidance**: Receiving recommendations for decision-making
- **Validation**: Checking outputs against requirements

### 4. Automation
No users reported automation use in 2023, but Survey 2 revealed emerging adoption.

## Workflow Integration

~60% of work-related LLM usage occurred within larger workflows. Only 11% utilized LLMs for multiple workflow steps. Most workflows were collaborative (69%). Before LLMs, 68% completed comparable tasks manually; 17% used other tools.

## Future Desired Use

### Data-Integrated Knowledge Management
Strong interest in querying proprietary organizational data — uploading source code, company policies, accumulated content to create searchable knowledge bases. One worker described wanting to "train a bot with all guild content to answer FAQs on Slack."

### Workflow Automation
Nearly 70% of Survey 2 participants selected automation as desired capability. Aspirational uses: calendar management, expense reports, scheduling — requiring API integration and workflow-level orchestration.

## Identified Challenges

- Inconsistent output quality requiring extensive editing
- Hallucinations undermining trust for specialized topics
- Privacy concerns with sensitive information
- Lack of repeatability in collaborative settings
- One worker: "I fundamentally don't trust the work of people who I know use LLMs...because I know how likely it is the work is poor quality."

## Design Implications

- Organizations should provide transparency about LLM capabilities
- Customization mechanisms for company-specific knowledge are critical
- Workers require LLMs embedded within existing tools
- Systems must facilitate efficient verification without excessive editing burden
- Future systems should address collaborative rather than just individual assistance

## Key Finding

LLMs are reshaping knowledge work incrementally rather than transformatively. Current applications focus on friction reduction while workers anticipate deeper integration addressing inefficiencies in information discovery across dispersed organizational systems.
