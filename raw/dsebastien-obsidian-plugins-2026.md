# The Best Obsidian Plugins for 2026

Based on Sébastien Dubois's comprehensive guide, here is the curated list of recommended plugins organized by category.

## Top 15 Essential Plugins

| Plugin | Purpose |
|--------|---------|
| **Dataview** | Query, filter, and display vault data with a query language |
| **Templater** | Powerful templating engine for creating note templates |
| **QuickAdd** | Rapidly capture content using templates and macros |
| **Tasks** | Track and manage tasks across the entire vault |
| **Periodic Notes** | Create daily, weekly, monthly notes automatically |
| **Kanban** | Build markdown-backed task boards |
| **Excalidraw** | Full-featured drawing and diagramming tool |
| **Auto Note Mover** | Automatically file notes based on configurable rules |
| **Omnisearch** | Full-text search across entire vault |
| **Life Tracker** | Visualize habits and metrics with charts |
| **Notebook Navigator** | Modern file explorer alternative |
| **Quick Switcher Plus Plus** | Enhanced file navigation by headings and symbols |
| **TaskNotes** | One note per task with time tracking |
| **Journal Bases** | Manage journaling with database views |
| **Local Backup** | Automate vault backup creation |

## Category Breakdown

### Journaling & Life Tracking
- **Periodic Notes**: Enables daily, weekly, monthly reviews with templates
- **Journal Bases**: Purpose-built views for periodic reviews
- **Life Tracker**: Visualizes tracked data with 12 chart types
- **Heatmap Calendar**: GitHub-style activity tracking
- **Tomorrow's Daily Note**: Quick access to next day's notes

### Task Management
- **TaskNotes**: Comprehensive task management with time tracking
- **Kanban**: Simple markdown-based board system
- **Tasks**: Advanced querying and filtering
- **Rollover Daily Todos**: Automatically carries incomplete tasks forward

### Querying & Data
- **Dataview**: Most powerful plugin for vault queries and live results
- **Dataview Serializer**: Converts Dataview queries to markdown output
- **Datacore**: Next-generation data engine (successor to Dataview)
- **OmniSearch**: Enhanced full-text search capabilities
- **Sentinel**: Automates property updates based on conditions

### Templating & Automation
- **Templater**: Advanced templating with functions and variables
- **QuickAdd**: Multi-purpose capture, templates, and macros
- **Auto Note Mover**: Rules-based automatic file organization
- **Expander**: Replace variables throughout vault

### Navigation & Productivity
- **Notebook Navigator**: Dual-pane modern file explorer
- **Quick Switcher Plus Plus**: Search by headings and symbols
- **Doubleshift**: Command palette via double-shift press
- **Reveal Active File**: Locate current file in hierarchy
- **Homepage**: Custom startup dashboard
- **Focus Mode**: Distraction-free writing environment
- **Recent Files**: Quick access to latest notes
- **Pane Relief**: Enhanced pane and tab management
- **Smart Random Note**: Explore vault with filtered randomization
- **Review**: Schedule periodic note reviews

### Visualization
- **Excalidraw**: Advanced sketching and diagramming
- **Mindmap**: Convert markdown to interactive mind maps
- **Maps**: Display location-based notes on interactive maps
- **Search in Canvas**: Enhanced canvas functionality
- **Graph Banner**: Display graph view as note banner

### Text Editing & Writing
- **Various Complements**: Auto-completion from vault content
- **Outliner**: Workflowy-style list manipulation
- **Zoom**: Focus on specific headings/sections
- **Text Transporter**: Advanced text manipulation
- **Notes Refactor**: Extract and reorganize content
- **Text Snippets**: Reusable text templates
- **Natural Language Dates**: Parse dates conversationally
- **Multi Tag**: Bulk tagging across folders
- **Paste URL Into Selection**: Streamlined link insertion
- **ProgressBar**: Visual progress indicators
- **Editing Toolbar**: Visual markdown formatting toolbar
- **Dictionary**: Built-in word definitions

### Content Capture & Media
- **Paste Image Renamer**: Auto-rename pasted images
- **Image Context Menus**: Right-click image utilities
- **Simple Embeds**: Auto-embed YouTube, Tweets
- **Extract URL**: Convert webpage URLs to markdown
- **Image in Editor**: Preview images in edit mode
- **Text Extractor**: OCR text from images/PDFs
- **Book Search**: Download book metadata

### Note Quality & Maintenance
- **Linter**: Auto-format and style notes consistently
- **Metadata Menu**: Structured property management
- **Clear Unused Images**: Remove orphaned attachments
- **Update Time**: Track creation and modification dates
- **Broken Links**: Identify and fix dead links
- **Find Unlinked Files**: Locate orphaned notes
- **List Modified**: Track recently changed notes
- **Remember Cursor Position**: Restore scroll location

### User Interface & Customization
- **Folder Note**: Create folder-level index notes
- **Hider**: Hide UI elements for cleaner interface
- **Fold Properties By Default**: Collapse metadata sections
- **Quiet Outline**: Dedicated outline sidebar
- **Insta Toc**: Auto-generate tables of contents
- **Settings Search**: Find settings quickly
- **Banners**: Add header images to notes
- **Iconize**: Add icons to folders and files

### Backup & Versioning
- **Local Backup**: Automated local backups
- **Obsidian Git**: Version control via Git
- **Time Machine**: Browse and restore previous versions

### Integration & Development
- **Pandoc**: Export to multiple formats
- **External Links**: Manage and track URLs
- **Terminal**: Embedded command-line interface
- **AdvancedURI**: Control Obsidian via custom URIs
- **BRAT**: Test beta plugins

## Notes from the Author

Dubois emphasizes that "you don't need plugins to get started" and recommends focusing on core plugins initially. He prioritizes Dataview, Templater, and QuickAdd as foundational tools. The guide covers 75+ plugins total and is integrated with his Obsidian Starter Kit product serving 1,000+ users.
