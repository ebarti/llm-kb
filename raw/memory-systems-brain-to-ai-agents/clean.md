# AI Meets Brain: Memory Systems from Cognitive Neuroscience to Autonomous Agents

## Core Taxonomy

Progressive framework: cognitive neuroscience → LLMs → autonomous agents.

### Biological Memory Types
- **Short-term memory**: Seconds to minutes, distributed sensory-frontoparietal networks, persistent neural activity
- **Long-term memory**: Extended retention, hippocampal-neocortical coordination
  - **Episodic**: Specific events and experiences
  - **Semantic**: Facts, concepts, general knowledge
  - **Procedural**: Skills and motor patterns

### AI Memory Parallels
- **Parametric memory**: Model weights (corresponds to semantic memory)
- **Working memory**: Context windows (mirrors working memory's limited capacity and positional bias)
- **Explicit external memory**: Vector databases, retrieval systems (parallels long-term storage)

## Hippocampal-Cortical Systems in AI

Agent architectures mirror biological consolidation through four phases:
1. **Encoding**: Raw interactions → structured records (flat, hierarchical, or generative paradigms)
2. **Consolidation**: Information gradually abstracts through reflection and reorganization
3. **Retrieval**: Similarity matching or multi-factor approaches reactivate relevant memories
4. **Reconsolidation**: Retrieved memories enter plasticity windows for updating

The hippocampus functions as an indexing system that reactivates distributed cortical traces.

## Working Memory in AI Agents

Context folding — dynamically managing information within reasoning trajectories:
- **Memory scheduling**: Time-slicing strategies borrowed from operating systems
- **Adaptive selection**: Learning-based mechanisms choose optimal scheduling rules
- **Autonomous evolution**: Self-triggering link generation updating context in real-time

## Episodic Memory Implementation

Captures "experiential memory that stores sequential interaction trajectories and contextual information":
- Tool-augmented trajectory logging
- Temporal flow structures with timestamps and importance scores
- Hierarchical tree structures for efficient navigation
- Feedback-based self-reflection (biological reconsolidation analog)

## Semantic Memory Architecture

Agent knowledge repository without tool dependencies:
- Cross-domain knowledge diffusion using lightweight abstraction operators
- Fixed-size memory pools in latent space balancing new/old knowledge
- Ebbinghaus forgetting curve principles for adaptive information elimination

## Key AI Architectures Inspired by Biology

- **Reflexion**: Self-reflection stored in contextual memory (not weight updates)
- **Memory Trees**: Hierarchical indexing through recursive summarization
- **Skill Libraries**: Exploration → structured composable programs (procedural memory)
- **Cognitive Maps**: Graph-based memory preserving relational information (hippocampal-entorhinal analog)
- **Dynamic Memory Evolution**: Autonomous reconstruction of semantic associations

## Memory Management Lifecycle

Four operational phases:
1. **Extraction**: Distilling raw information into structured records
2. **Updating**: Dynamic within-trajectory and cross-trajectory maintenance
3. **Retrieval**: Similarity or multi-factor matching mechanisms
4. **Application**: Contextual augmentation or parameter internalization

## Significance

This survey provides the most comprehensive mapping between biological and artificial memory systems to date, directly informing the design of next-generation AI agents with brain-like memory capabilities.
