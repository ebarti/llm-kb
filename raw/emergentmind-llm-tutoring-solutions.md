# LLM-Powered Tutoring Solutions

## Core Definition

LLM-powered tutoring solutions are systems that integrate advanced language models into modular architectures, enabling dynamic content generation and adaptive feedback.

## Key Systems

### Physics-STAR
GPT-4o core for content generation, user interface, adaptation engine for performance-driven prompt adjustment, and feedback module tracking hints and correctness. Results: 100% post-test score increase on information-based questions; +5.95% time efficiency gains.

### GLOSS
Social skills tutor with drag-and-drop scenario builder, narrative graph formalization, conversational simulation interface, and analysis/visualization tools.

### LeafTutor & Stitch
Programming tutors integrating LLM roles with code comparison engines, retrieval-augmented document stores, and assignment-grounded prompt scaffolding.

### IntelliCode
Multi-agent system featuring centralized learner profiles tracking mastery, decay-weighted performance, misconception logs, and Bayesian update rules.

### Tutorly
Improved programming outcomes from 61.9% to 76.6% correct answers.

### AgentTutor
24-30 percentage point advantage over single-turn baselines in code correctness.

### LLMKT
>93% accuracy for LLM-generated correctness labels; >0.4 Krippendorff's alpha on knowledge component relevance.

## Pedagogical Approaches

- Two-parameter IRT cognitive models for proficiency quantification
- Knowledge tracing with per-turn mastery estimation
- Hierarchical guardrails using finite-state tutors
- Multi-level hint selection based on mastery levels
- Graduated scaffolding based on performance thresholds

## Domain Coverage

- STEM: physics, mathematics, computer science, quantum computing, CUDA programming
- Soft skills: communication and empathy training
- Teacher professional development
- Video-based interactive learning

## Major Challenges

- Simulated student dialogue fails to match real behavior in knowledge gain and error types
- Limited longitudinal evaluation beyond short-term gains
- Multimodal integration (video, audio, traces) remains underdeveloped
- Ethical concerns including fairness, bias detection, and hallucination monitoring
- Infrastructure demands for scalable microservice architectures
