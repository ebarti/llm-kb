# 10 Things Developers Want from their Agentic IDEs in 2025

By Kate Holterhoff, RedMonk

The evolution from "AI Code Assistants" (2023-2024) to "Agentic IDEs" (2025) reflects a fundamental change: tools moved from reactive suggestion to autonomous execution. Developers now delegate entire workflows to agents rather than seeking help with individual functions.

## The 10 Requirements

### 1. Background Agents
Queue tasks for overnight execution, returning to review completed pull requests without real-time supervision.

### 2. Persistent Memory
Agents must remember past decisions and project history across sessions — living systems of record, not stateless tools.

### 3. Predictable Pricing
Transparency in token usage, session costs, and clear spending limits. 2025 saw pricing volatility: Cursor's usage-based shift, Claude Code limits, Replit's cost overruns.

### 4. Model Context Protocol (MCP)
Anthropic-introduced standard achieved rapid adoption. Seamless integration with Google Drive, Slack, GitHub, databases, and internal systems without custom coding.

### 5. Multi-Agent Orchestration
Dashboards showing parallel agent work, with capabilities to pause, redirect, or terminate tasks mid-execution. Primarily accessible to senior+ engineers.

### 6. Spec-Driven Development
requirements.md and design.md files serve as contracts between humans and AI, providing structural guidance and verification checkpoints.

### 7. Reliability
Despite claimed uptime, developers reported consistent issues: Windsurf latency, Antigravity model overload errors, daily incidents on status pages. Flow state depends on consistent performance.

### 8. Human-in-the-Loop Controls
Fine-grained permissions prevent autonomous destructive actions (deletions, database writes, deployments). Necessary friction for safety.

### 9. Rollbacks
Checkpoint systems enabling instant state restoration. "It is better to roll back: this way you save tokens" and improve output quality.

### 10. Skills
Reusable, version-controlled workflow modules encoding institutional knowledge. Anthropic's internal study found "44% of Claude-assisted work consisted of tasks they wouldn't have enjoyed doing themselves."

## Market Landscape (2025)

Notable entrants: Windsurf (Cognition acquisition), ByteDance's Trae, AWS Kiro, IBM Project Bob, Augment Code (first ISO/IEC 42001 certified), Zencoder's Zenflow, JetBrains Junie, Google Antigravity.

CLI options gaining traction: Claude Code, Cline CLI, Continue.dev, Aider, OpenDevin.

## Future Trajectory

Developer role evolves toward architecture, system design, and quality judgment. AI handles mechanical work while humans retain responsibility for judgment and design decisions.
