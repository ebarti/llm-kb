# Devin AI: The First Autonomous Software Engineering Agent

## Overview

Devin is the world's first fully autonomous AI software engineer, created by Cognition Labs (CEO Scott Wu, CTO Steven Hao), funded by Peter Thiel's Founders Fund.

## Capabilities

- Write, run, and test code autonomously
- Plan and execute complex engineering tasks requiring thousands of decisions
- Recall relevant context at every step
- Learn over time and fix mistakes
- Equipped with shell, code editor, and browser in sandboxed compute environment

## Performance

Evaluated on SWE-bench: correctly resolved 13.86% of issues end-to-end, far exceeding previous state-of-the-art of 1.96% at time of announcement. (Note: by 2026, leading agents score 75%+ on SWE-bench Verified.)

## Evolution

### Devin 1.0 (March 2024)
First announcement. $500/month pricing.

### Devin 2.0 (April 2025)
Reduced pricing from $500/month to $20/month (Core plan). Added:
- **Devin Wiki**: Machine-generated software documentation
- **Devin Search**: Interactive search and Q&A engine for codebases

## SWE-bench Landscape (2026)

SWE-bench has become the primary benchmark for evaluating LLM software engineering agents:
- **SWE-bench Lite**: 300 curated instances
- **SWE-bench Verified**: Human-validated subset for fair evaluation
- **SWE-bench Pro**: Complex, realistic programming challenges
- **SWE-bench+**: Enhanced to address solution-leak risks

Current leaders (2026): Claude Opus 4.5 leads with 0.809 on SWE-Bench Verified.

Performance progression: 1.96% (2024) → ~75% (2025-2026 on Verified subset).
