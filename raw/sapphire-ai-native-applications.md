# AI-Native Applications: A Framework for Evaluating Enterprise Software

Sapphire Ventures defines AI-native applications as those where AI is fundamental to the user experience rather than supplementary. Four core characteristics:

1. Built on foundational AI capabilities (learning from datasets, generating novel outputs)
2. Deliver outcomes transcending traditional constraints of speed, scale, and cost
3. Designed for continuous improvement through model advancements and user feedback
4. Include proprietary AI technology alongside off-the-shelf components

## Five-Dimensional Evaluation Framework (The "5 D's")

### 1. Design
- Create new interaction models beyond chat interfaces
- Leverage multi-modal inputs
- Accelerate feedback loops through non-disruptive user signals
- Balance commodity components with proprietary capabilities

### 2. Data
- Rigorous end-to-end data management
- Leverage dormant organizational data
- Create proprietary datasets competitors cannot easily replicate
- "Gone are the days where having the most data as an incumbent platform drove the greatest technical moat"

### 3. Domain Expertise
- Translate domain-specific activities into AI workflows
- Synthesize information at scale with speed
- Marry global knowledge from foundational models with local organizational insights and industry-specific databases

### 4. Dynamism
- Optimize performance and cost tradeoffs in real-time
- Create generative customer journeys adapting to individual preferences
- Enable hyper-personalization across users, teams, and departments

### 5. Distribution
- Flexible pricing: seat-based, consumption-based, outcome-based
- Enable new business models: software-enabled services, agentic systems

## Market Momentum

- $8.5 billion invested in GenAI-native applications through October 2024
- 47+ AI-native apps generating $25M+ ARR (up from 34 at year's start)
- Major funding: Perplexity, Magic, Sierra, Abridge

## Notable AI-Native Companies

- **Abridge**: Transforms patient audio into clinical notes using multi-LLM architecture
- **Glean**: Trains custom models and builds organization-specific knowledge graphs
- **Perplexity.ai**: Integrates web citations into generated responses
- **Cognition**: Native code editor for collaborative AI-assisted development

Long-term winners differentiate across multiple dimensions simultaneously, not merely through incremental feature additions.
