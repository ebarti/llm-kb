# Project Xanadu

The first hypertext project, founded in 1960 by Ted Nelson. Envisioned a "digital repository scheme for world-wide electronic publishing."

## Key Innovations

### Hypertext (1965)
At Harvard in 1960, Nelson conceived of document storage/display/editing with visual version comparison ("intercomparison"). In 1965 ACM paper, introduced "zippered lists" and coined "hypertext."

### Transclusion
Compound documents could incorporate pieces from other documents. Central concept distinguishing Xanadu from later systems.

### Bidirectional Links
If Document A linked to Document B, the connection was visible and navigable from both ends — contrasting the web's one-way hyperlinks.

### The Name (1967)
Named after Coleridge's poem "Kubla Khan" while Nelson worked for Harcourt, Brace.

## Development Timeline
- 1972: Cal Daniels completed demonstration version
- 1974: Nelson published Computer Lib/Dream Machines
- 1979: Nelson, Roger Gregory, Mark S. Miller, Stuart Greene developed tumblers (transfinite number addressing)
- 1981: Literary Machines published
- 1983: Met Autodesk founder John Walker at Hackers Conference
- 1988: Autodesk bought Xanadu Operating Company
- 1992: Autodesk divested; financial struggles
- 1995: Wired called it "longest-running vaporware story in computing history"
- 1998: Source code released as Project Udanax
- 2007: XanaduSpace 1.0
- 2014: OpenXanadu made available on the Web

## 17 Original Rules
Key principles included:
- Unique identification of servers, users, documents
- Visible, bidirectional links from all endpoints
- Built-in royalty mechanisms for content access
- Secure, redundant storage with automatic distribution
- Open communication protocols

## Relationship to the World Wide Web
Contentious. Nelson's team grew defensive as Web gained dominance. OpenXanadu creators claimed Berners-Lee adopted their ideas, calling the Web "a bizarre structure."

## Legacy
Concepts — transclusion, version control, granular linking, micropayments — anticipated features later embraced by contemporary systems. Werner Herzog's 2016 documentary Lo and Behold featured Nelson.
