# Copilot for Obsidian

## Core Features

Copilot for Obsidian is "The Knowledge Work Agent That Grows with Your Second Brain."

**Context & Search**: Users can add notes, folders, highlighted text, PDFs, and images as chat context. The system supports fetching URLs, YouTube transcripts, and tweets on demand. Search capabilities include both lexical options (no setup required) and semantic indexing for deeper recall across thousands of notes.

**Commands & Integration**: Quick inline commands accessible via right-click menu or command palette, maintaining tight integration with Obsidian's native interface.

**Projects**: Each project receives isolated workspaces with customizable models, system prompts, and chat history. Supports 50+ file types including PDFs, images, and Office documents.

**Composition & Editing**: A composer feature allows users to rewrite or expand notes with diff preview before accepting changes.

## AI Capabilities

**Model Agnostic Approach**: Works with multiple AI providers including OpenAI, Anthropic, Google, LM Studio, Ollama, and any OpenAI-compatible model. Users can switch providers without ecosystem lock-in.

**Self-Hosting**: Supports local or self-hosted models for keeping "your AI stack truly private."

## Vault Search & RAG

Surfaces related notes through inline citations from notes and live sources. Drag-and-drop linking of discovered notes.

## Data Ownership

All data — including memory, chat history, system prompts, and custom commands — exists as plain markdown files within users' vaults, avoiding database lock-in.
