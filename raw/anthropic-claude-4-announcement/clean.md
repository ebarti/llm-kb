# Introducing Claude 4

## Release Date
May 22, 2025

## Models Released
- **Claude Opus 4**: "The world's best coding model" -- sustained performance on complex, long-running tasks. 72.5% on SWE-bench Verified, 43.2% on Terminal-bench.
- **Claude Sonnet 4**: Significant upgrade from Sonnet 3.7. 72.7% on SWE-bench Verified. Balances performance and efficiency.

## Key Features

### Extended Thinking with Tool Use (Beta)
Both models can alternate between reasoning and tool use during extended thinking, including web search.

### Parallel Tool Execution
Models can use multiple tools simultaneously.

### Memory Capabilities
With local file access, Opus 4 excels at creating "memory files" to store key information for improved task awareness.

### Reduced Shortcuts
Both models are 65% less likely to engage in shortcut behaviors on agentic tasks compared to Sonnet 3.7.

### Claude Code GA
Now generally available with:
- Native VS Code and JetBrains IDE integrations
- GitHub Actions support
- Extensible SDK for custom agent development

## Pricing (Same as Claude 3 Opus/Sonnet)
- Opus 4: $15/$75 per million tokens
- Sonnet 4: $3/$15 per million tokens

## Availability
Claude.ai, API, Amazon Bedrock, Google Cloud Vertex AI

## Top-tier results in:
Reasoning, coding, multilingual tasks, long-context handling, honesty, and image processing.
