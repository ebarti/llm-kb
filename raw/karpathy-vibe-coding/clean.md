# Vibe Coding

## Definition
AI-assisted software development where developers describe projects in natural language prompts to LLMs, which generate source code automatically. The approach emphasizes accepting AI-generated code without thorough review, relying on iterative testing and follow-up prompts.

## Origin
Coined by Andrej Karpathy on February 2, 2025, in a viral X post (4.5M+ views). He described it as: "fully give in to the vibes, embrace exponentials, and forget that the code even exists." Developers "see stuff, say stuff, run stuff, and copy paste stuff, and it mostly works." He acknowledged this suits "throwaway weekend projects" rather than production systems.

## Cultural Impact
- Merriam-Webster listed it as "slang & trending" (March 2025)
- Collins English Dictionary Word of the Year for 2025
- Y Combinator reported 25% of Winter 2025 startups had 95% AI-generated codebases
- Linus Torvalds employed the technique for hobby projects

## Criticisms
- CodeRabbit (Dec 2025): AI co-authored code contained 1.7x more major issues than human code
- VeraCode (Oct 2025): LLMs improved at generating functional code but not secure code
- METR (July 2025): Experienced developers 19% slower using AI tools despite believing they'd be faster
- GitClear (2020-2024): Code refactoring dropped from 25% to under 10%, duplication increased 4x
- January 2026 research: Vibe coding weakens open-source ecosystems

## Associated Tools
Cursor Composer, GitHub Copilot, Replit Agent, Claude Code, Google Antigravity, Lovable, OpenAI Codex

## Notable Critics
- Andrew Ng: Term misleadingly suggests engineers "go with the vibes"
- Simon Willison: Thoroughly reviewing code disqualifies the practice as true "vibe coding"
